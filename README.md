# Online Retail Data Analysis
## Project Overview
This project analyzes an Online Retail dataset to identify
sales trends, customer behavior and revenue patterns.

## Tools Used
- Python
- Pandas
- NumPy
- SQL
- MySQL
- Power BI

## Project Workflow

Python
↓
Data Cleaning
↓
SQL Analysis
↓
Power BI Dashboard

## Python
Used Python and Pandas for data cleaning and preprocessing.

## SQL
Used MySQL to perform:
- Total orders analysis
- Total revenue calculation
- Product quantity analysis
- Country-wise revenue analysis

## Power BI
Created an interactive dashboard to visualize the analysis.

## Files
- `1.data_cleaning_.ipynb` — Python data cleaning
- `online_retail_analysis.sql` — SQL queries
- `online retail PBI` — Power BI dashboard
